## Project Structure

This repository contains all materials related to the research project **"Using Generative AI Tools – Boon or Bane"**. The data is organised into the following folders:

### Literature Review documents
This folder contains all background research materials, including journal articles, conference papers, books, and other published sources used to support the study.

### Quantitative Analysis
This folder includes all numerical data and analysis files, such as survey questions, raw and cleaned survey datasets (e.g., CSV, Excel), Python scripts, and quantitative analysis reports.

### Qualitative Analysis
This folder stores qualitative research data, including interview transcripts, interview protocols, consent forms, and reports summarising insights and findings from qualitative analysis. Data visualisations may also be included here.

### Drafts and Reports
This folder contains all written outputs throughout the research process, including draft proposals, working papers, conference submissions, and the final research report.

### Additional Materials
This folder includes supplementary materials such as information sheets, images, and other media files that support the research project.

## Notes
- All files are organised to ensure easy navigation and accessibility.
- Sensitive data (e.g., consent forms and interview transcripts) should be handled with appropriate access control.
- Version control is maintained using Git to track changes and support collaboration.
